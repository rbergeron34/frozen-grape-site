# Frozen Grape · Soft Pip

Approved direction: **02 / Pip — Soft**. Pip is a single frosted purple grape with a curved stem, icy-blue leaf, small arms and feet, and a quiet, friendly expression. Keep the soft printed-paper texture and simple face. The studio tagline is **“Worth a spot on your screen.”**

## Asset kit

- [Primary transparent character](../public/brand/pip/hello.png): open eyes and a small smile, for the main mark, website and announcements.
- [Happy transparent character](../public/brand/pip/happy.png): closed eyes and a smile, for confirmations and small celebrations.
- [Pip at a MacBook](../public/brand/pip/macbook.png): seated and working, used on the Texas studio map. Retain enough size for the laptop and face to read clearly.
- [Wordmark lockup](../public/brand/pip/wordmark.svg): Pip with the Frozen Grape Studios name. This SVG embeds the raster character; the mascot is not fully vector. The website uses live text in BrandLockup.tsx.
- [Social card](../public/brand/pip/social-card.png): 1200 × 630 PNG, also generated by the Open Graph and Twitter metadata routes.
- [Browser icon](../public/brand/pip/icon.png) and [Apple touch icon](../public/brand/pip/apple-touch-icon.png).
- [Approved concept sheet](../public/brand/pip/approved-concept.png): reference, not a website image.

Previous imagery is retained in public/brand/legacy and the original public/brand/logo-* files. The new brand uses /brand/pip/.

## Usage

Pair Pip with the Frozen Grape name in navigation, footers and standalone announcements. Leave clear space around the stem, leaf and feet. Preserve its aspect ratio, colors and transparency. Avoid heavy outlines, glow, stretching, busy backgrounds and extra frost effects. Use the full-resolution PNG for larger artwork and the provided icons for browser surfaces.

Pip is the studio character; individual apps keep their own artwork. Use occasional appearances at the opening, studio map and successful signup. Decorative instances have empty alternative text; adjacent text supplies the accessible label.

Use Plus Jakarta Sans for the website and live wordmark. The downloadable SVG includes a sans-serif fallback; raster metadata exports use the renderer's bundled sans-serif. Keep copy short, direct and warm.

## Implementation

Pip.tsx is the shared decorative image component; BrandLockup.tsx pairs it with live brand text. src/lib/brand-images.tsx renders metadata images from the same primary asset. No new client animation or graphics library is required.

## Artwork provenance

Production assets were prepared with the **built-in Imagegen tool**, using the approved Soft Pip sheet as the edit reference for the primary and happy poses, then the primary pose as reference for the MacBook pose. All character outputs have alpha transparency; the approved sheet remains unchanged. The exact production prompt set is recorded in [pip-prompts.md](pip-prompts.md).
